## Built

- D041: version 2 per-collection provider checkpoints, v1 compare-and-swap upgrade, Google head probes, fair reconciliation and bounded connection turns. - Persistent connection-scoped HTTP 429 cooldowns, including refresh endpoints. Refresh cooldowns commit under the current grant lock; concurrent refresh cannot replace the grant before the cooldown is stored. Manual sync returns a redacted 429 and retry header. No shared client-wide quota limiter is claimed.
